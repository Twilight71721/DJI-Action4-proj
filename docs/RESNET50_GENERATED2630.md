# ResNet50-FPN：2630 张合成数据泛化实验

用户指定使用当前已生成的 2630 张图片。实际启动时完成 2650 张，按完成批次及帧号固定选取前 2630 张，不随继续渲染变化。数据位于 `dataset/action4-resnet2630-20260922`，RGB、相机内参、位姿与目标框均复制固定；清单保存来源、分组和每张 RGB 的 SHA-256。

## 划分与训练

沿用生成器动作段划分：2120 张训练（4240 实例）、500 张验证（1000 实例）、10 张测试（20 实例）。不同集合的动作段不交叉，测试场景不在训练程序可见的 `trainval` 根目录。当前测试集偏小，是分批渲染顺序造成的，不为凑比例随机拆分相邻帧。新验证/测试图与旧 200 张训练图没有完全相同的 RGB 哈希；不排除共享场景设计或相近姿态。

结构为 ResNet50-FPN，FPN 128 通道，8 个角点热图；输入 256×256，热图 64×64，真值 bbox 的 1.3 倍正方形裁剪。ImageNet 归一化，sigmoid + top9 加权解码。相机实体尺寸和角点定义与旧数据相同。

从 ImageNet 预训练 backbone 和新 FPN 开始训练，不加载旧过拟合权重，不启用 `--overfit`。100 轮、batch 16、前 2 轮冻结 backbone；AdamW，head lr=0.001，backbone lr=0.0001，weight_decay=0.0001，余弦学习率，composite loss。没有新增随机裁剪或颜色增强，本次主要检查扩充数据及留出验证后的表现。相比旧过拟合实验，数据源版本、划分、正则化均有变化，不是纯数据量消融。

最佳权重仅按验证集平均角点误差选择。训练实例和验证实例缓存到 CPU RAM，以减少重复解码开销；训练加载 worker=0。渲染任务保持原状。

## 状态与复现

运行目录 `outputs/resnet50_generated2630_20260922`：

- `status.json`：数据准备、当前完成轮数、最新及最佳验证指标、评估或失败状态。
- `train.log`、`metrics.csv`：训练日志和逐轮记录。
- `command.json`、`config.json`、`provenance.json`：完整命令、参数和输入/代码指纹。
- `best.pth`、`last.pth`：最佳与最新模型。
- `review/index.html`：训练结束后自动生成新旧模型泛化对比。

启动入口为 `scripts/run_resnet_generated.py --dataset dataset/action4-resnet2630-20260922 --output outputs/resnet50_generated2630_20260922`，使用 `.venv-hccepose/bin/python`。入口会拒绝复用已有状态/训练目录。

## 评估

训练完成后，`compare_resnet_generalization.py` 使用同样的新合成验证/测试实例评估旧 200 张过拟合模型和新模型，输出平均误差、PCK@5、P90 等指标。像素单位为 256×256 裁剪图坐标。原始预测和有效角点掩码存入 NPZ。

真实诊断固定使用此前 YOLO 实验的 8 张真实测试帧，分别使用同一组人工估计框及固定 YOLO 预测框裁剪；两种 ResNet 对每个框使用相同输入。它们没有可靠的 8 角点标签，不能计算真实角点准确率，报告只作可视化比较。该真实视频已用于合成设计，不是独立拍摄盲测。YOLO 的人工检测框不能自动当作 ResNet 的 8 角点真值。

新增两个训练管理/报告脚本，未修改已有训练和网络实现。数据检查验证了划分隔离、实例计数、RGB 哈希无重复及新留出集与旧 200 图无完全重复；抽查角点投影预览位于运行目录 `label_preview.jpg`。

验证：`test_net.py` 与 `test_bop_bb8.py` 合计 38 个测试通过；新脚本语法检查通过。训练和评估源码备份在 `source_snapshot/`。

## 完成结果

100 轮完成，连同缓存和评估共 2434 秒，按验证平均误差选中第 50 轮。新模型验证平均误差 6.55 px、PCK@5 70.26%；测试平均误差 105.71 px、PCK@5 0.625%。旧参考模型对应为 4.01 px/83.90% 和 5.77 px/80.63%。重要限制：旧模型训练覆盖所有原动作族（包括此次验证/测试的动作族），因此不具备同等动作留出的公平性，不能归因于数据量。抽查真实固定框结果仍存在角点错位/聚集，未见可确认的泛化改善。
