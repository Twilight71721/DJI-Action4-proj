## 证据与改动

- 参考原视频抽帧 `outputs/video_reference_audit/head_left_rgb_raw/frames_full/frame_000000.jpg` 和 `frame_000500.jpg`，尺寸 3248×2464。
- 新入口 `scripts/fit_action4_reference_2d.py` 保存人工对应点、拟合的 K/R/t、重投影误差和焦距敏感性结果。用原 GLB 渲染透明背景，只在诊断页面上与真实帧并排/叠加；真实帧像素没有进入 Blender 材质。
- 第 0 帧：左右相机后屏和顶部可见。第 500 帧：左右相机镜头面可见，后屏标记不应出现。可见面由拟合结果的法向点积检查。
- `scripts/render_action4_wrist_hccepose.py` 将顶部文字旋转改为 `(-pi/2, pi, 0)`，使文字表面朝局部 +Y 外侧。原白色纸片位置保持 +Y。
- `scripts/action4_dynamic_scene.py` 的后屏 AprilTag 尺寸和位置改为第 0 帧检测结果对应的估计值：左纸片中心 (17.1,4.1) mm、边长 29.6 mm；右中心 (20.3,4.6) mm、边长 27.7 mm。是通过估计姿态反投影所得，不是物理测量值。黑码四角原图观测保存于 `detected_tags.json`。
- GLB 顶点、面、UV、尺寸和主体拓扑未修改。

## 坐标检查纠错

机身前面 +Z、后屏 -Z、顶部 +Y、安装底面 -Y。检查过程中曾根据上下倒置的正面预览误判为 -Y 顶面；查询实际观察相机矩阵后发现检查相机绕光轴多转了 180°，因此撤销该误判。不能只看图片上下方向推断模型局部轴；应同时检查投影矩阵和坐标轴。
