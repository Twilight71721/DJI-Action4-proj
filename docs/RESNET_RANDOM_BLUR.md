# 清晰与模糊输入混合（2026-09-23）

沿用已有3305张训练模型作为历史基线，不强制重训清晰5000张基线。后续若使用5000张加模糊，差异同时包含数据扩充和增强，不能把全部变化归因于模糊；比较量化指标应先确认测试集合相同，旧模型不能在其已训练的图上被称为独立测试。

## 实现

新增 bop_bb8/augment.py 的 RandomBlurDataset，包装确定性训练数据/CPU缓存。只对 image 做对称 Gaussian blur，不改 keypoints_2d、heatmap、valid、K_input、R_m2c、t_m2c。返回新的字典和图像，不原地修改缓存。对 ImageNet 标准化图像做归一化高斯滤波与先滤波RGB再标准化数学等价，反射边界已用测试核对。

只包装训练集，验证集保持原样，包括 --overfit 模式下的原始验证副本。概率为0时不包装、不消耗增强随机数。torch随机数由原训练seed及DataLoader worker机制管理。随机变换在缓存之后，每次取样重新抽样，故清晰/模糊是期望比例，不保证每个batch恰好一半。

在既有 scripts/train_heatmap.py 命令上添加：

```
--blur-probability 0.5 --blur-sigma 0.4 1.6 --blur-kernel-size 9
```

sigma单位为最终输入裁剪像素，本方案输入256×256。此参数是起点，不是最佳配置结论。默认 --blur-probability 0.0，保留旧基线行为。不要修改 Gaussian 监督热图的 sigma 来模糊训练图；两个sigma意义不同。

“框清晰”指标签准确且不模糊。人工框线、角点线条不应画入网络输入。预览页面下排在模糊之后叠加二维框/八角点，只供检查，不参与训练。相机真实外轮廓属于RGB，会受到模糊影响；本实现不是保留轮廓而只模糊内部纹理的分割操作。

原5000张图片不被覆盖，也没有生成5000张固定模糊副本。在线增强让清晰样本持续保留，并允许同一图片在不同轮次有不同退化。
