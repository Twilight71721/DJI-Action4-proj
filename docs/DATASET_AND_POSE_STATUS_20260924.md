## 1. 目前真正用于 ResNet 训练的数据

当前基础数据为 action4-cleanblur5000-20260923（`dataset/action4-cleanblur5000-20260923/manifest.json`）。已核对磁盘：5000 张 clean、5000 张 blur。

| 划分 | 基础合成帧 | 清晰 + 模糊保存图 | 相机实例数（每图两个） |
|---|---:|---:|---:|
| train | 4000 | 8000 | 16000 |
| val | 500 | 1000 | 2000 |
| test | 500 | 1000 | 2000 |
| 合计 | 5000 | 10000 | 20000 |

每张模糊图对应一张清晰图，二者具有相同场景、姿态与几何标签。因此 10000 张保存图不等于 10000 个独立场景，也不等于 10000 种新姿态。验证/测试分别报告清晰和模糊结果；选模型使用清晰验证集。框/角点线用于检查图，不画入模型训练输入。

数据按完整渲染任务分组，共 293 个任务、20 个参考动作/姿态 family。train/val/test 的 scene ID 交集均为零，旧 3305 版成员划分保留。但不同集合共享参考姿态 family，所以这不是“从未见过动作或姿态族”的测试。

原始清晰训练图中 8000 个实例的粗视角标签统计如下；模糊配对没有增加新视角：

| 元数据视角标签 | 实例 | 比例 |
|---|---:|---:|
| side_right | 1696 | 21.2% |
| rear_screen | 3609 | 45.1% |
| top | 850 | 10.6% |
| front_lens | 806 | 10.1% |
| side_left | 1039 | 13.0% |

粗视角标签分布并不均匀，且它们不能证明某个真实视频姿态被准确复现。20 个 family 也不等于逐帧姿态覆盖证明。

## 2. 服务器最近完成的背景混合训练

最近回传的 background_mixed_30ep 分析（`outputs/server_return_background_20260924/background_mixed_30ep/ANALYSIS.md`） 对应已完成的 30 轮训练。它在上面的配对数据与既有 5000 模型基础上继续训练，使用：

- 统一背景池 **1536 张**：1024 张外部图片 + 从 256 个真实视频帧抽取的 512 个背景裁片。不是 1536 个姿态，也没有达到 5000+ 背景。
- 80% 概率在线替换背景、20% 保留原图；每轮重新组合，未预先导出一套新的大规模姿态数据集。
- 清晰/模糊实例保持 1:1。替换背景的模糊分支先合成再模糊，角点几何不变。
- 实际这次训练仍有中心 ±5% 和 padding 1.2～1.4 的裁剪扰动。“关闭裁剪扰动并扩充新姿态”的下一轮尚未正式运行。
- 相机 mask 是原渲染完整机身投影轮廓；轮廓内保留原图已有的遮挡像素，不是逐像素完美的纯相机抠图。

真实视频背景按用户要求混合使用，所以同视频真实帧的效果展示不是独立盲测。ResNet 目前仍没有一套可信、完整的真实八角点/6D 姿态 GT 训练集。

YOLO 是另一套任务：48 张真实框标注中 32 张用于训练、8 张验证、8 张测试；混合 940 张合成图，真实训练帧重复采样。这些 2D bbox 不能直接当 ResNet 的八角点或 6D 真值。
